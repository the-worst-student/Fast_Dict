## Описание проекта

В рамках данного задания реализован собственный аналог словаря Python — `FastDict`.

Структура данных основана на **splay-дереве**, реализованном на C++ и обёрнутом в Python с помощью `pybind11`.

---

## Реализованный функционал

Класс `FastDict` реализует интерфейс, аналогичный `collections.abc.MutableMapping` и поддерживает следующие операции:

- `__getitem__(key)`  
  Получение значения по ключу.  
  При отсутствии ключа выбрасывается `KeyError`.

- `__setitem__(key, value)`  
  Вставка нового элемента или обновление существующего значения.

- `__delitem__(key)`  
  Удаление элемента по ключу.  
  Если ключ отсутствует — выбрасывается `KeyError`.

- `__len__()`  
  Возвращает количество элементов в словаре.

- `__contains__(key)`  
  Проверка наличия ключа (`key in dict`).

- `__iter__()`  
  Итерация по ключам словаря.

---

## Дополнительные методы

- `keys()`  
  Возвращает список всех ключей.

- `values()`  
  Возвращает список всех значений.

- `items()`  
  Возвращает список пар `(ключ, значение)`.

## Особенности реализации

- В основе лежит **splay-дерево**, обеспечивающее амортизированную сложность \( O(\log n) \).
- При каждом доступе элемент перемещается ближе к корню (splay-операция).
- Ключи сравниваются через операцию `<`:
  - для Python-объектов используется вызов `__lt__`
- Значения могут быть любыми Python-объектами.
- Реализация выполнена с использованием шаблонов C++.
